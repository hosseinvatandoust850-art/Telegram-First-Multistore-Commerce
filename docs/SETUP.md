# راهنمای تنظیمات اولیه (Setup Wizard)

این راهنما فرآیند تکمیل تنظیمات اولیه برنامه را به‌صورت گام‌به‌گام توضیح می‌دهد.

---

## 🎯 Setup Wizard چیست؟

Setup Wizard یک رابط کاربری ساده و قدم‌به‌قدم است که به شما کمک می‌کند بدون نیاز به دانش فنی، فروشگاه خود را راه‌اندازی کنید.

### چه زمانی نمایش داده می‌شود؟

- ✅ اولین باری که برنامه را باز می‌کنید
- ✅ وقتی تنظیمات کامل نشده باشد
- ❌ بعد از تکمیل تنظیمات، دیگر نمایش داده نمی‌شود

---

## 📋 مراحل Setup Wizard

### مرحله ۱: ایجاد حساب مدیر

در این مرحله، حساب کاربری مدیر اصلی را ایجاد می‌کنید.

#### اطلاعات مورد نیاز:

| فیلد | توضیح | حداقل طول |
|------|-------|-----------|
| **نام** | نام کامل شما | ۲ کاراکتر |
| **ایمیل** | ایمیل معتبر برای ورود | - |
| **رمز عبور** | رمز عبور امن | ۸ کاراکتر |
| **نام فروشگاه** | نام فروشگاه شما | ۱ کاراکتر |
| **شناسه فروشگاه** | آدرس یکتا (اختیاری) | - |
| **زبان** | زبان پیش‌فرض فروشگاه | - |
| **ارز** | ارز پیش‌فرض | - |

#### نکات مهم:

- ✅ ایمیل باید معتبر باشد (بعداً برای بازیابی استفاده می‌شود)
- ✅ رمز عبور باید قوی باشد (ترکیب حروف، اعداد و نمادها)
- ⚠️ شناسه فروشگاه اگر خالی باشد، به‌صورت خودکار از نام فروشگاه ساخته می‌شود
- ⚠️ پس از ایجاد، تغییر شناسه فروشگاه ممکن نیست

#### پس از کلیک روی "Create Admin":

1. ✅ حساب کاربری شما ساخته می‌شود
2. ✅ فروشگاه اولیه ایجاد می‌شود
3. ✅ توکن دسترسی صادر می‌شود
4. ➡️ به مرحله بعد هدایت می‌شوید

---

### مرحله ۲: اتصال ربات تلگرام

در این مرحله، ربات تلگرام فروشگاه را متصل می‌کنید.

#### چگونه ربات بسازیم؟

1. **در تلگرام به @BotFather پیام دهید**

2. **دستور `/newbot` را بفرستید**

3. **نام ربات را وارد کنید**
   ```
   My Store Bot
   ```

4. **نام کاربری ربات را وارد کنید**
   ```
   mystore_bot
   ```
   > ⚠️ باید به `bot` ختم شود

5. **توکن را کپی کنید**
   ```
   1234567890:AAE...
   ```

#### در Setup Wizard:

1. توکن را در فیلد "Bot Token" وارد کنید
2. روی **Connect Bot** کلیک کنید

#### بررسی‌های خودکار:

سیستم به‌صورت خودکار:

- ✅ اعتبار توکن را بررسی می‌کند
- ✅ اطلاعات ربات را دریافت می‌کند
- ✅ نام کاربری ربات را ثبت می‌کند
- ✅ Webhook را تنظیم می‌کند

#### وضعیت Webhook:

| وضعیت | معنی | اقدام |
|-------|------|-------|
| ✅ Registered | Webhook با موفقیت ثبت شد | ادامه دهید |
| ⚠️ Pending | URL هنوز HTTPS نیست | بعد از تنظیم دامنه دوباره تلاش کنید |
| ❌ Failed | خطا در ثبت | لاگ را بررسی کنید |

#### تست ربات:

1. در تلگرام، ربات خود را باز کنید
2. دستور `/start` را بفرستید
3. باید پیام خوش‌آمدگویی دریافت کنید

---

### مرحله ۳: تنظیم پرداخت

در این مرحله، روش‌های پرداخت را پیکربندی می‌کنید.

#### گزینه‌های پرداخت:

##### الف) TON (ارز دیجیتال)

**مزایا:**
- ✅ تأیید خودکار
- ✅ کارمزد کم
- ✅ بین‌المللی

**تنظیمات مورد نیاز:**

| فیلد | توضیح |
|------|-------|
| **آدرس کیف پول** | آدرس TON فروشگاه شما |
| **شبکه** | mainnet (واقعی) یا testnet (آزمایشی) |

> ⚠️ **هشدار:** در تولید، همیشه از `mainnet` استفاده کنید مگر برای تست.

##### ب) پرداخت دستی

**مزایا:**
- ✅ ساده و بدون نیاز به کیف پول
- ✅ مناسب برای کارت بانکی محلی
- ✅ انعطاف‌پذیر

**نحوه کار:**

1. مشتری سفارش را ثبت می‌کند
2. رسید پرداخت را آپلود می‌کند
3. سفارش به حالت "در انتظار بررسی" می‌رود
4. مدیر پرداخت را تأیید یا رد می‌کند

**تنظیمات:**

- دستورالعمل پرداخت را وارد کنید
- مثال: "لطفاً مبلغ را به شماره کارت ... واریز کنید"

##### ج) هر دو روش

هر دو روش بالا را همزمان فعال کنید تا مشتریان انتخاب کنند.

#### پس از تنظیم:

1. ✅ روش‌های پرداخت ذخیره می‌شوند
2. ✅ تنظیمات در دیتابیس ثبت می‌شود
3. ➡️ به مرحله بعد هدایت می‌شوید

---

### مرحله ۴: بررسی ذخیره‌سازی

در این مرحله، سلامت فضای ذخیره‌سازی فایل‌ها بررسی می‌شود.

#### چرا ذخیره‌سازی مهم است؟

فایل‌های زیر نیاز به فضای پایدار دارند:

- 📷 تصاویر محصولات
- 📄 فایل‌های دیجیتال
- 🧾 رسید‌های پرداخت
- 💾 پشتیبان‌های دیتابیس

#### انواع ذخیره‌سازی:

##### ۱. S3 (توصیه می‌شود)

**مزایا:**
- ✅ پایدار و ماندگار
- ✅ مقیاس‌پذیر
- ✅ پشتیبان‌گیری خودکار

**سرویس‌های سازگار:**
- Cloudflare R2
- AWS S3
- MinIO
- DigitalOcean Spaces

**تنظیمات:**

اگر از S3 استفاده می‌کنید، متغیرهای زیر را در Railway تنظیم کنید:

```
S3_ENDPOINT=https://account-id.r2.cloudflarestorage.com
S3_BUCKET=my-bucket
S3_ACCESS_KEY_ID=access-key
S3_SECRET_ACCESS_KEY=secret-key
S3_REGION=us-east-1
```

##### ۲. Volume محلی Railway

**مزایا:**
- ✅ ساده
- ✅ رایگان (تا حد مشخص)

**معایب:**
- ⚠️ فقط روی یک سرویس قابل دسترسی
- ⚠️ محدودیت حجم

**تنظیمات:**

1. در Railway، به سرویس Web بروید
2. تب **Volumes** → **New Volume**
3. مسیر Mount: `/app/storage`
4. حجم پیشنهادی: 1GB

سپس متغیر زیر را اضافه کنید:
```
STORAGE_DIR=/app/storage
```

#### نتیجه بررسی:

| وضعیت | معنی | اقدام |
|-------|------|-------|
| ✅ Healthy & Persistent | ذخیره‌سازی سالم و پایدار است | ادامه دهید |
| ⚠️ Healthy but Local | سالم اما موقت | Volume اضافه کنید |
| ❌ Unhealthy | مشکل در ذخیره‌سازی | سریعاً رفع کنید |

#### هشدارها:

⚠️ **اگر پیام هشدار دیدید:**

> "Storage is not properly configured. Files may be lost on redeploy."

این یعنی فایل‌های آپلودشده با هر بار استقرار جدید پاک می‌شوند.

**راه‌حل:**
1. یا S3 پیکربندی کنید
2. یا Volume به Railway اضافه کنید

### مرحله ۵: پایان تنظیمات

در این مرحله نهایی، همه چیز تأیید و قفل می‌شود.

#### بررسی نهایی:

سیستم به‌صورت خودکار بررسی می‌کند:

- [ ] حساب مدیر ساخته شده است
- [ ] فروشگاه ایجاد شده است
- [ ] ربات تلگرام متصل است
- [ ] پرداخت پیکربندی شده است
- [ ] ذخیره‌سازی بررسی شده است

#### دکمه "Complete Setup":

با کلیک روی این دکمه:

1. ✅ وضعیت Setup به `COMPLETED` تغییر می‌کند
2. ✅ Setup Wizard قفل می‌شود
3. ✅ امنیت افزایش می‌یابد
4. ➡️ به پنل مدیریت هدایت می‌شوید

#### پس از تکمیل:

- ❌ Setup Wizard دیگر نمایش داده نمی‌شود
- ❌ نمی‌توانید به مراحل قبل برگردید
- ✅ می‌توانید از پنل مدیریت همه چیز را تغییر دهید

## 🔒 امنیت Setup Wizard

### محافظت در برابر سوءاستفاده

#### قفل شدن پس از تکمیل

بعد از تکمیل Setup:

- تمام مسیرهای `/setup/*` قفل می‌شوند
- فقط مدیران لاگین‌شده می‌توانند تنظیمات را تغییر دهند
- تلاش برای دسترسی مستقیم با خطای 403 مواجه می‌شود

#### جلوگیری از ایجاد مدیر تکراری

- فقط یک مدیر اولیه می‌تواند از طریق Setup ساخته شود
- مدیران بعدی باید از پنل مدیریت اضافه شوند

#### ثبت رویدادها

تمام مراحل Setup در دیتابیس ثبت می‌شوند:

- زمان شروع
- زمان تکمیل
- تغییرات هر مرحله

## ↩️ ادامه تنظیمات ناتمام

### اگر Setup را نیمه‌کاره رها کردید:

نگران نباشید! می‌توانید بعداً ادامه دهید.

#### بازگشت به Setup:

1. برنامه را باز کنید
2. به‌طور خودکار به آخرین مرحله ناتمام هدایت می‌شوید
3. از همان‌جا ادامه دهید

#### وضعیت ذخیره می‌شود:

اطلاعات زیر حفظ می‌شوند:

- ✅ حساب مدیر (اگر ساخته شده)
- ✅ فروشگاه (اگر ایجاد شده)
- ✅ تنظیمات تلگرام (اگر متصل شده)
- ✅ تنظیمات پرداخت (اگر پیکربندی شده)

## 🛠️ عیب‌یابی Setup

### مشکل: صفحه Setup نمایش داده نمی‌شود

**علت احتمالی:** Setup قبلاً تکمیل شده است.

**راه‌حل:**
1. سعی کنید با ایمیل خود لاگین کنید
2. اگر رمز عبور را فراموش کرده‌اید، از بازیابی استفاده کنید
3. اگر واقعاً نیاز به Setup مجدد دارید، با پشتیبانی تماس بگیرید

### مشکل: خطا در ایجاد حساب مدیر

**علت:** ایمیل تکراری است.

**راه‌حل:**
- از ایمیل دیگری استفاده کنید
- یا اگر ایمیل خودتان است، سعی کنید لاگین کنید

### مشکل: توکن تلگرام نامعتبر است

**علت:** توکن را اشتباه کپی کرده‌اید یا منقضی شده است.

**راه‌حل:**
1. به @BotFather بروید
2. دستور `/revoke` را بفرستید
3. توکن جدید بگیرید
4. دوباره امتحان کنید

### مشکل: Webhook ثبت نمی‌شود

**علت:** URL برنامه HTTPS نیست.

**راه‌حل:**
1. فعلاً ادامه دهید
2. بعد از تنظیم دامنه یا فعال‌سازی HTTPS
3. از پنل مدیریت روی "Register Webhook" کلیک کنید

### مشکل: بررسی ذخیره‌سازی شکست می‌خورد

**علت:** neither S3 nor Volume is configured.

**راه‌حل:**
1. فعلاً ادامه دهید (با هشدار)
2. قبل از آپلود فایل، Volume اضافه کنید یا S3 پیکربندی کنید

## 📊 وضعیت Setup

### مشاهده وضعیت

می‌توانید وضعیت Setup را ببینید:

**API:**
```
GET /api/setup/state
```

**پاسخ نمونه:**
```json
{
  "ok": true,
  "state": {
    "step": "TELEGRAM_CONFIGURED",
    "adminUserId": "uuid",
    "storeId": "uuid",
    "telegramBotConnected": true,
    "paymentsConfigured": false,
    "storageVerified": false
  },
  "isComplete": false,
  "canModify": true
}
```

### مراحل Setup:

| مرحله | کد | توضیح |
|-------|-----|-------|
| شروع | `PENDING` | هیچ کاری انجام نشده |
| مدیر ساخته شد | `ADMIN_CREATED` | حساب مدیر ایجاد شده |
| فروشگاه ساخته شد | `STORE_CREATED` | فروشگاه اولیه ایجاد شده |
| تلگرام متصل شد | `TELEGRAM_CONFIGURED` | ربات تلگرام وصل است |
| پرداخت تنظیم شد | `PAYMENTS_CONFIGURED` | روش‌های پرداخت پیکربندی شده |
| ذخیره‌سازی بررسی شد | `STORAGE_VERIFIED` | فضای ذخیره‌سازی سالم است |
| تکمیل | `COMPLETED` | همه مراحل تمام شده |

## 🔄 بازنشانی Setup (فقط برای توسعه)

> ⚠️ **هشدار:** این عمل فقط برای محیط توسعه مناسب است و در تولید توصیه نمی‌شود.

اگر نیاز به بازنشانی کامل Setup دارید:

```sql
DELETE FROM "Setting" WHERE key = '_system_setup' AND "storeId" IS NULL;
```

سپس برنامه را ری‌استارت کنید.
